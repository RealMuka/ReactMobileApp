# FITCALORIA

Простой учебный дневник питания на обычных HTML, CSS и JavaScript. В проекте нет фреймворков, библиотек интерфейса, сборщика и внешних зависимостей.

## Запуск

1. Распакуй папку проекта.
2. Открой `index.html` в современном браузере. Если браузер ограничивает локальное сохранение, запусти простой локальный сервер, например расширение Live Server в VS Code.
3. Данные сохраняются в `localStorage` текущего браузера. Это учебный проект без серверной регистрации и синхронизации между устройствами.

## Структура

- `index.html` — разметка страниц, формы и модальные окна.
- `css/styles.css` — оформление и адаптация под размеры экрана.
- `js/app.js` — логика приложения, дневник, продукты, настройки, расчёты и сохранение.

### Как устроен `js/app.js`

Файл разбит на нумерованные разделы, функции внутри раздела связаны одной задачей:

1. Константы и справочные данные — приёмы пищи, макросы, диапазоны значений, база продуктов.
2. Состояние приложения — переменные, которые меняются во время работы.
3. Работа с `localStorage` — загрузка, сохранение и восстановление данных.
4. Утилиты — доступ к элементам, числа, округление, экранирование текста.
5. Расчёты питания — итог по порции, по приёму пищи и за день.
6–8. Отрисовка — дневник, каталог продуктов, статистика с графиком.
9. Навигация, тема и уведомления.
10. Настройки и расчёт норм — чтение формы, проверка, формулы, сохранение.
11. Работа с дневником и продуктами — добавление, удаление, сброс.
12. Обработчики событий — по одному обработчику на действие.
13. Инициализация — подписка на события и первый расчёт экранов.

## Что умеет

- Добавлять продукты из базы и искать их по названию.
- Создавать свои продукты с БЖУ на 100 г.
- Добавлять и удалять еду в завтраке, обеде, ужине и перекусе.
- Автоматически считать калории и БЖУ дневника.
- Рассчитывать ориентировочную суточную норму по данным пользователя.
- Сохранять изменения в браузере и вести простую историю веса.
- Автоматически менять интерфейс для телефона и компьютера. В настройках есть опция принудительного широкого режима ПК.
- Переключать светлую и тёмную темы.

## Формулы расчёта

Если пользователь указал процент жира, рассчитывается безжировая масса:

`Безжировая масса = вес × (1 − процент жира / 100)`

Основной обмен рассчитывается по формуле Katch–McArdle:

`BMR = 370 + 21.6 × безжировая масса (кг)`

Если процент жира не указан, используется формула Mifflin–St Jeor:

- Мужчины: `BMR = 10 × вес + 6.25 × рост − 5 × возраст + 5`
- Женщины: `BMR = 10 × вес + 6.25 × рост − 5 × возраст − 161`

Ориентировочная суточная энергия получается умножением BMR на коэффициент активности и поправку цели. Белок рассчитывается как 2 г/кг безжировой массы для поддержания/набора и 2.3 г/кг безжировой массы для дефицита калорий. Жиры — ориентировочно 0.8 г/кг безжировой массы. Углеводы заполняют оставшиеся калории.

Это оценки, а не точное измерение обмена веществ. Результат зависит от точности введённого процента жира, реальной активности и индивидуальных особенностей. Процент жира не следует считать точным, если он получен приблизительным визуальным измерением.
